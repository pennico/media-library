# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating (in issues, pull requests, discussions, or any other
project space) you agree to uphold it.

In short:

- Be respectful and constructive, and assume good intent.
- Welcome newcomers.
- Keep criticism about the work, not the person.

Harassment, personal attacks, and publishing others' private information
are not acceptable.

## Reporting

Report unacceptable behavior to the maintainer,
[@pennico](https://github.com/pennico). If the matter is sensitive, use the
repository's private reporting form (Security tab → "Report a
vulnerability") and say that it is a conduct report. It reaches only the
maintainer, and reports are handled confidentially.

The maintainer may remove, edit, or reject comments, commits, code,
issues, and other contributions that do not follow this code of conduct.
The maintainer may also temporarily or permanently ban contributors for
behavior they deem harmful, as described in the Contributor Covenant's
enforcement guidelines.
